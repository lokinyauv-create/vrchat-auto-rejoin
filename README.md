## Українська

Заснула в інстансі, а прокинулась у меню з помилкою «зʼєднання перевищило час очікування»? Ця програма сама повертає тебе назад, і ніхто не бачить, що ти «зникла».

### Встановити (одна команда)

```bash
curl -fsSL https://raw.githubusercontent.com/lokinyauv-create/vrchat-auto-rejoin/main/get.sh | bash
```

Видалити: `bash ~/.local/share/vrchat-auto-rejoin/uninstall.sh`

### Що вона робить

1. Помічає, що тебе викинуло: зʼявилося вікно з помилкою або ти довго сидиш поза світом.
2. Чекає, поки повернеться інтернет, і дає VRChat ~20 секунд повернутися самому.
3. Перезапускає VRChat **у той самий інстанс**, до 10 разів.
4. Якщо інстансу вже немає, відкриває **твій дім у режимі «Друзі+»**, щоб до тебе могли зайти. Так само, якщо VRChat закинув тебе в приватний дім.

Працює з будь-яким інстансом: вона завжди памʼятає, де ти була востаннє.

### Вікно «Вильоти VRChat»

Є в меню програм. Показує кожен вилет: коли, чому (зник інтернет, перезавантажився роутер чи збій у VRChat), що зробила програма і скільки ти була поза світом. Окрема вкладка показує всі обриви інтернету.

### Як вона запускається

- Якщо встановлено **[VR Auto Launcher](https://github.com/lokinyauv-create/vr-autolauncher)**, програма додається туди. Вона вмикається разом із VRChat і вимикається через 3 хвилини після нього.
- Якщо його немає, вона працює як фонова служба (`systemctl --user`).
- `… | bash -s -- --service` примусово ставить службу.

### Що потрібно

- Linux, VRChat зі Steam (Proton), `python3`.
- Для вікна журналу потрібен PySide6. Встановлювач спробує поставити його сам.
- [VRCX](https://github.com/vrcx-team/VRCX), необовʼязково: з нього береться домашній світ (для «Друзі+») і назви світів.

## English

Fell asleep in an instance and woke up in the menu with "your connection timed out"? This program puts you back automatically.

### Install (one command)

```bash
curl -fsSL https://raw.githubusercontent.com/lokinyauv-create/vrchat-auto-rejoin/main/get.sh | bash
```

Uninstall: `bash ~/.local/share/vrchat-auto-rejoin/uninstall.sh`

### What it does

1. Notices you were kicked: VRChat shows the connection error, or you sit outside any world for a while.
2. Waits for the internet to come back and gives VRChat ~20 s to rejoin by itself.
3. Restarts VRChat **into the same instance**, up to 10 times.
4. If that instance is gone, it opens **your home world as Friends+** so friends can still join you. Same if VRChat dumped you into a private home.

It follows whatever instance you were in last.

### "VRChat kicks" window

In your app menu. It lists every kick: when, why (internet drop, router reboot or VRChat-side problem), what the program did and how long you were out. Another tab lists every internet outage.

### How it starts

- With **[VR Auto Launcher](https://github.com/lokinyauv-create/vr-autolauncher)** installed, it is added there: it starts with VRChat and stops 3 minutes after VRChat closes.
- Without it, it runs as a background service (`systemctl --user`).
- `… | bash -s -- --service` forces the service.

### Requirements

- Linux, VRChat from Steam (Proton), `python3`.
- PySide6 for the log window (the installer tries to install it).
- [VRCX](https://github.com/vrcx-team/VRCX), optional: it supplies your home world (for Friends+) and world names.

### Files

- `~/.local/share/vrchat-auto-rejoin`: the program
- `~/.local/state/vrchat-auto-rejoin`: `rejoin.log`, `net.log`, `events.jsonl` (history; kept on uninstall)

Not affiliated with VRChat Inc. It only reads VRChat's log files and starts VRChat through Steam with a normal `vrchat://launch` link.
